# BNBU-Souvenir-Shop
BNBU纪念品商店网站 | Web团队课程项目

## 项目简介
基于XAMPP开发的纪念品商店网页，实现商品浏览、用户注册登录、订单提交、收据展示功能。
本人负责前端页面与PHP后端衔接，PHP与MySQL数据库连接，完成数据交互。

### 技术栈
- Frontend：HTML, CSS, JavaScript
- Backend：PHP
- Database：MySQL
- Environment：XAMPP

## 目录结构
- `src/`：网页源码 html、php、图片资源
- `database/`：MySQL建表SQL脚本
- `docs/`：项目文档、PPT、项目说明文档

## 运行步骤
1. 使用XAMPP启动Apache与MySQL服务
2. 在phpMyAdmin导入 `members.sql` 和 `purchase.sql`
3. 将src内网页文件放到xampp/htdocs目录
4. 浏览器访问 `localhost/clothes.html`
